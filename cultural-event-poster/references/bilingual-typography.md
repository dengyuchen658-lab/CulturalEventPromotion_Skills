# 双语字体与排版策略

- 中英文共享同一事实母本、画布比例、视觉概念和信息层级，但允许分别换行和重排。
- 活动名称、机构、日期、时间、地点、票务、网址和二维码目标逐项对应；官方译名优先，非官方译名标记 `pending`。
- 中文标题优先使用清晰的宋体、黑体或活动策略指定的候选字体；英文使用相匹配的衬线或无衬线字体。最终以环境可用且有授权的字体为准。
- H1 为活动名称，H2 为主题/传播语，H3 为日期时间地点和行动，H4 为主办方、票务细则和二维码。
- 英文版可调整文本框、字号、字距和行距，不得为了填入文本而压缩到不可读。
- 检查数字、日期、时间、价格、专名、大小写、标点、孤行、溢出、二维码安全区和移动端可读性。
