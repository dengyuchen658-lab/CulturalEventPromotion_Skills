# 工作流与 Gate

## 阶段图

```text
输入资料 → 00 文件盘点 → 01 解析与素材识别 → 02 内容母本
→ Gate 1：事实能否支持策略？ → 03 活动分类与策略
→ Gate 2：方向能否进入生成？ → 04 概念、素材与提示规划
→ 05 主视觉生成 → 06 正式文字与语言版本排版
→ Gate 3：是否可标为交付候选？ → 07 QA 与定向返工
→ Gate 4：是否可正式交付？
```

## 阶段输入、输出与通过条件

| 阶段 | 输入 | 输出 | 通过条件 |
|---|---|---|---|
| 00 盘点 | 原始资料包 | `input-manifest.json` | 全部文件有记录，未知格式已标记 |
| 01 解析 | 文件清单 | 提取文本、图片索引、失败记录 | 关键文件可读，失败有替代路径 |
| 02 母本 | 提取结果、用户说明 | `brief.yaml` | 关键字段有状态、来源和置信度 |
| 03 分类 | 内容母本 | 主/次类型、属性、策略 | 主类型置信度至少 medium，或不影响探索 |
| 04 概念 | 策略、文化资料 | 2–3 个方向、素材和提示计划 | 方向有文化依据且结构不同 |
| 05 生成 | 已确认方向 | 主视觉候选 | 无正式文字依赖，主题相关 |
| 06 排版 | 主视觉、正式内容 | 各语言版海报 | H1–H3 清晰，正式信息来自母本 |
| 07 QA | 候选成品 | 质量报告、返工任务 | Critical 全部通过，Major 已解决或接受 |

## Gate 1：事实就绪

必须确认活动名称、主类型线索、日期或明确的待定策略、地点或线上形式、目标受众、行动方式、语言版本和输出范围。日期、地点、主办方、票务、活动名称出现冲突时，不进入正式生成。

## Gate 2：方向就绪

必须具备传播目标、主类型、H1–H3、画布比例、文化依据、已选择方向或用户的快速试稿授权。版权状态未知的素材不得设为正式核心资产。

## Gate 3：候选就绪

正式文字必须由可控排版加入；Logo、二维码不得由生成模型重绘；各语言版本可对应；画布与数量符合母本。未确认字段必须清楚标为概念稿占位，不能伪装为终稿。

## Gate 4：正式交付

关键事实全部 `confirmed`，素材授权无阻断，Critical QA 全部通过，导出规格和数量正确，且人工已确认文化相关性、传播效果和最终视觉方向。

## 回退矩阵

| 问题 | 回退目标 |
|---|---|
| 文件漏读、来源混淆 | 00–01 输入层 |
| 名称、日期、地点、票务错误 | 02 内容母本 |
| 传播重点与活动性质不符 | 03 分类与策略 |
| 文化元素无关、错置或刻板化 | 04 文化依据与设计命题 |
| 主体、气氛或构图偏题 | 04–05 概念或生成 |
| 正式文字错误、溢出、低对比 | 06 排版层 |
| 格式、尺寸、数量错误 | 导出层 |
