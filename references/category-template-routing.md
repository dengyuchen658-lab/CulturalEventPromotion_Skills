# 艺术街区、工作坊与体育赛事：强制成员模板路由

## 适用与优先级

用户明确要求这三类活动的所有海报使用成员设计模板。本文件是主 Skill 对六个成员包的接入规则；模板不是可选案例。现有资料解析、统一内容母本、活动分类、双语事实映射、质量检查、交付流程继续适用。字体、配色角色、排版、构图机制和模板专项 QA 由所选模板约束，优先于通用自由选风格建议。用户后续明确更改某项时，仅覆盖该项。

- 艺术街区：主内容为艺术街区开放、艺术季、社区文化、邻里共创、城市漫步或街区生活，且具有公共参与与地方生活依据；仅作为活动地点的街区不触发。读取艺术街区策略，不能把所有 `festival` 都套入本模板。
- 工作坊：主行为是学习、制作、研究、讨论或共创，使用抽象工作坊模板。地点在艺术街区仍按工作坊处理；连续制作步骤不能冒充多个独立活动。
- 体育赛事：以比赛、对抗、竞速或电竞竞技为主行为，按 `sports` 路由；体育场只是举办地点时不触发。按赛名长度与主图需求选择成员包内 central 或 bottom-band，不另选自由版式。
- 同时出现多类内容时，依主活动与观众主要行为选择一套完整机制，不混用街区纸张／剪影与工作坊抽象／反白。独立宣传某个工作坊的海报仍须走工作坊模板。
- 每个语言版本单独路由；不得用英文模板机械替换中文字，也不得将中文模板的全部参数照搬英文。其他语言没有对应成员模板时先确认适配要求，不自行新建风格。

## 固定什么、替换什么

固定成员包指定的字体、文字颜色角色、对齐关系、构图机制和可适配范围。默认画布为 2400×3000、4:5；用户指定另一输出尺寸时依模板等比规则处理，比例冲突或内容容量不足时给出具体待确认调整，不能自行换模板或删事实。

每次替换真实名称、时间、地点、机构、导师、费用、名额、报名和参与条件。艺术街区按实际活动重新生成动作与简洁道具、重建遮罩；四活动槽位是模板容量，实际数量不符时记录调整并确认，不凑数或重复标签。工作坊从材料、工艺、参与动作推导抽象图形与主题色，不固定蓝晒图形或蓝色。固定模板不意味着复制示例活动事实或品牌。

中文版街区标题自身不旋转；英文版标题与前纸同角旋转、两行共享测量字号，并采用内容大小纸张与底部三行分组。这是两版各自规则，不合并为一套参数。工作坊不使用街区纸张、人物标签或网格。

## 接入现有工作流

1. 统一 `brief.yaml` 仍是事实母本。按选中模板映射其所需的 `brief.json`、锁定文案、`layout-text.json` 和语言映射；它们是派生文件，冲突时回到统一母本修正。
2. 在现有项目工作区保存 `routing.json`，记录类别、语言、证据、`template_id`（如 `art-district/en`）、模板路径、适配记录和用户明确覆盖项。模板里的默认输出路径不另建平行项目，全部交付继续归入现有项目工作区与清单。
3. 三类活动已选定模板方向，不再要求从三种自由版式中选风格。概念规划用于本题内容锚点、动作／道具或主题抽象图形；文化、专名、事实、授权问题仍按原流程确认。
4. 按成员包执行可控排版、资产生成与合成。`skia-canvas`、`sharp` 是运行依赖，不随模板提供；查找实际运行时或用可测量的等效工具，不硬编码他人环境路径。依赖不可用时明确未执行，不宣称完成成图验证。
5. 合并通用 QA 和所选模板全部专项 QA，核对真实字体、配色、实际字形边界、溢出、移动预览与图形机制。工作坊重点核对实际交叠字形局部反白及白字对比度至少 4.5:1；街区逐场景核对宽渐消、两条轮廓和网格遮罩。

## 资源来源

六个模板来自用户提供的小组成员包，按原文件内容接入；参考图片和示例文案只用于识别机制。字体清单和来源状态见 [字体索引](../assets/fonts/font-catalog.md)。包内附带文件不等于已核验所有字体的使用或对外分发授权。

## 双版任务范围

艺术街区、工作坊和其他文化类别一样，每次必须同时调用中文与英文模板并交付两版完整海报。上表语言行是同一任务的两个子流程，不是二选一；既有图形资产可复用，两版各按自身字体和排版执行。

## 体育赛事专项接入

上游内容母本先确定上版文案并保存 `poster-copy`、`locked_copy`；体育模板负责完整映射，不重新筛除字段。两版复用同一主图、构图模式、可见边界和比例；不能因为英文较长就切换模式或改变主图大小。正文按词组换行，标题组统一调整，实际加载七份包内字体并检查字形。

固定江城律动黑主标题、Harmony 信息、标题／副标题／宣传语白色及其余信息浅白色，赞助左上、组织右上、单行宣传语、年份／主标题／副标题共中轴、底部场馆与时间实际字形底边对齐。主图为赛事相关的4—6块平面纸片，背景为主题色渐变加轻网点纸纹；不使用写实球体、无主题光圈、猜测的球员或伪Logo。无赞助事实时省略赞助组，缺失Logo只用资料里的文字署名。

体育模板允许对已锁定文案增加布局映射与调整，保留字号角色、文字颜色和对齐机制；超出允许范围的更改仍需用户确认。模板 Markdown 明确要求年份、标题、副标题在 x1200 中轴；若旧 `layout-spec.json` 的 bottom-band 年份仍为 x120/left，按入口及文字机制的中轴要求执行并记录，避免复制过期参数。模板示例只用于结构参考，不是赛事事实。

专项 QA 还需检查至少两项运动识别线索、4—6块解构结构、主体可见宽度、共享色系、非三维质感、图文60px间距、上/下140px边距、44px组织／赞助／场馆信息、局部文字背景对比与双版同图几何。
